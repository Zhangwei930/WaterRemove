# UI 表示言語 (日本語 / 简体中文)

環境設定「全体設定 › 表示言語 (Language)」と初回設定ダイアログで、UI の表示言語を
日本語と简体中文から選べる。設定値は `Settings::ui_language` (`UiLanguage`)。

## 仕組み

ソースの UI 文字列は日本語のまま持ち、**egui が文字を配置する直前**に翻訳表で差し替える。
呼び出し側のコードは `t("…")` 等で包む必要がない。

```
ui.label("設定") ──► WidgetText / Painter ──► text_translation フック ──► 翻訳関数 ──► "设置"
                         (vendor/egui)            (vendor/egui)            (src/i18n.rs)
```

| 場所 | 役割 |
| --- | --- |
| `vendor/egui/src/text_translation.rs` | 翻訳関数の登録口と、`WidgetText` / `Painter` からのフック。詳細は [vendor/egui/PATCHES.md](../vendor/egui/PATCHES.md) |
| `src/i18n.rs` | `apply_language` (言語切替) と翻訳表の照合。`tr()` は egui を通らない場所用 |
| `assets/i18n/zh-Hans.json` | 简体中文の翻訳表 (`include_str!` で埋め込み) |
| `scripts/i18n_tool.py` | 翻訳表の抽出・取り込み・検査 |

- 言語は `App::update` が毎フレーム `apply_language` で適用する (同じ言語なら何もしない)。
  起動時は `lib.rs` で初回フレーム前に適用する。
- 訳の無い文字列は日本語のまま表示する。
- widget id は訳す前の文字列から作られるため、言語切替で id は変わらない。

### 翻訳表の照合規則

1. `strings`: 描画される文字列全体と完全一致。
2. `patterns`: `format!` で組み立てる文字列用。`{0}` `{1}` … が可変部分。訳文で順番を入れ替えてよい。
   可変部分は、それ自体が `strings` に完全一致するときだけ訳す。
3. 1・2 で見つからなければ、前後の空白を除いた本体、次に改行ごとの各行で引き直す。

中国語は日本語と漢字を共有するため、誤訳を防ぐ制限がある。

- 固定部分に仮名が無いパターン (`{0}件` `{0}以上` など) は、可変部分が漢字・仮名を含まない値
  (数値など) か、`strings` で訳せる値のときだけ使う。中国語の「打开文件」が `{0}件` に
  一致して書き換わるのを防ぐ。
- 固定部分が記号だけのパターン (`{0} - {1}` など、`i18n_tool.py generic` が作る) は、
  可変部分のどれかが訳せたときだけ使う。ファイル名・パス・時刻をつなぐ書式
  (`{0}.{1}` `{0}\{1}` `{0}:{1}` など) は対象外。
- 訳した結果は再び渡されても訳さない (`strings` の訳文集合と、照合結果のメモで判定)。

### 利用者の文字列を訳さない

ファイル名やフォルダ名が翻訳表の原文と一致すると (例: フォルダ名「写真」)、そのまま
訳されてしまう。利用者の文字列を描く箇所では `egui::text_translation::NoTranslationGuard`
を保持し、その範囲の UI 文言だけを `crate::i18n::tr` で明示的に訳す。

現在ガードを置いている箇所:

- `app/grid_paint.rs::draw_cell` (サムネイル一覧のセル)

詳細一覧・フォルダツリー・アドレスバー・ツールチップのファイル名は未対応
(原文と完全一致した場合だけ訳される)。

### egui を通らない文字列

次は egui の配置を通らないため、フックでは訳されない。

- OS のタイトルバー: メインウィンドウは `app.rs` で `i18n::tr` を当てて送信する。
  別ウィンドウのタイトル (主にファイル名) は訳さない。
- ネイティブのダイアログ・メニュー (ファイル選択、エクスプローラーのコンテキストメニュー、
  タスクトレイメニューなど)。
- mIV Remote の Web UI (`htdocs` / `crates/remote-web`)。
- ログ、`keymap.ini` のコメント、書き出すファイルの内容。

## 翻訳の追加・更新

```bash
# ファイル別の未訳件数
python3 scripts/i18n_tool.py stats
# 指定範囲の未訳を JSON で書き出す (訳文欄を埋めて merge する)
python3 scripts/i18n_tool.py todo src/ui_dialogs -o todo.json
python3 scripts/i18n_tool.py merge todo.json
# 記号だけの書式パターンを追加する (訳文 = 原文)
python3 scripts/i18n_tool.py generic src/ui_dialogs
# 検査 (プレースホルダの整合、訳文が別の原文になっていないか)。問題があれば exit 1
python3 scripts/i18n_tool.py check
python3 scripts/i18n_tool.py check --stale   # ソースから消えた原文も警告する
```

抽出対象は `src/` の文字列リテラルのうち日本語を含むもの。`#[cfg(test)] mod`、`tests.rs` /
`*_test.rs`、`src/bin/`、ログ・`panic!`・`assert!` 系の引数は除く。`format!` / `write!` の
書式文字列は、`{}` `{name}` `{:.1}` などを出現順に `{0}` `{1}` … へ置き換えたパターンになる。
可変部分が隣接する書式 (`{}{}`) は照合できないため取り込まない。

UI 文字列を変更したら、翻訳表の該当原文も更新する (`check --stale` で古い原文が分かる)。
訳の無い文字列は日本語で表示されるだけなので、翻訳の追加は後からでもよい。

環境設定、ダイアログ (`src/ui_dialogs`)、メニュー・ショートカット・操作名 (`keymap.rs`
`ring_shortcut.rs` `context_menu_model.rs`)、設定値のラベル (`settings.rs`)、メイン画面
(`ui_main.rs`)、画像フルスクリーン (`ui_fullscreen.rs`)、トースト等 (`app.rs`)、サムネイル

タグビュー、ブックマーク、スマートフォルダ、サブ展開、外部ツール、表示トリム。

未翻訳の主な範囲: 補正パネル・ローカル調整 (`ui_adjustment_panel.rs` `local_adjust_effect_ui.rs`)、
テキスト注釈 (`ui_text.rs`)、消しゴム・隠蔽 (`ui_erase.rs` `ui_conceal.rs`)、mIV Remote の設定 UI
(`remote_ipc/ui.rs`)、更新履歴 (`version_highlights.rs`)、EXIF タグ名 (`exif_reader.rs`)。
`python3 scripts/i18n_tool.py stats` で最新の件数を確認できる。

## テスト

- `src/i18n.rs` の単体テスト: 照合規則 (完全一致・空白・行ごと・パターン・記号パターン・
  漢字だけのパターン・二重翻訳の防止) と、同梱翻訳表が読み込めること。
- `vendor/egui` の `text_translation::tests`: フックと `NoTranslationGuard`。
- `settings.rs`: `ui_language` の保存・読込と、未知の値を日本語へ戻す前方互換。
